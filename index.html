Mengakses Gambar dari GitHub

Panduan lengkap cara menggunakan gambar yang disimpan di repository GitHub

1. Raw GitHub URL

Cara paling umum menggunakan URL raw dari GitHub

https://raw.githubusercontent.com/{username}/{repo}/{branch}/{path}

2. GitHub Pages

Jika repository mengaktifkan GitHub Pages

https://{username}.github.io/{repo}/{path}

3. jsDelivr CDN

Menggunakan CDN untuk performa lebih baik

https://cdn.jsdelivr.net/gh/{user}/{repo}@{branch}/{path}

Cara Kerja - GitHub API

API untuk List File di Direktori

GET https://api.github.com/repos/{owner}/{repo}/contents/{path}?ref={branch}

API ini mengembalikan daftar semua file dan folder dalam direktori yang ditentukan.

Contoh Response

[
  {
    "name": "logo.png",
    "path": "images/logo.png",
    "size": 12345,
    "type": "file",
    "download_url": "https://raw..."
  }
]

Catatan Penting

  • • GitHub API memiliki rate limit 60 request/jam untuk pengguna tanpa autentikasi
  • • Hanya bekerja untuk repository public
  • • Maksimal 1000 file per direktori

Drag files here atau klik untuk memilih

Tulis Commit Message & Klik "Commit changes"

Selesai!

Gambar Anda sekarang sudah terupload dan bisa diakses dengan URL:

https://raw.githubusercontent.com/faridridwan1378/varsha-catalog/main/gambar%20buah/nama-file.jpg

Upload via Git Command Line

# 1. Clone repository (jika belum)

git clone https://github.com/faridridwan1378/varsha-catalog.git

# 2. Masuk ke folder repository

cd varsha-catalog

# 3. Copy gambar ke folder "gambar buah"

cp /path/to/local/image.jpg "gambar buah/"

# 4. Tambahkan file ke staging

git add "gambar buah/image.jpg"

atau gunakan git add . untuk semua file

# 5. Commit perubahan

git commit -m "Add new fruit image"

# 6. Push ke GitHub

git push origin main

Catatan

  • • Pastikan Git sudah terinstall di komputer
  • • Anda perlu login ke GitHub via terminal
  • • Gunakan Personal Access Token jika menggunakan HTTPS

Upload via GitHub API (Advanced)

Untuk upload otomatis menggunakan JavaScript/API:

async function uploadToGitHub(file) {
    const token = 'YOUR_GITHUB_TOKEN';
    const owner = 'faridridwan1378';
    const repo = 'varsha-catalog';
    const path = `gambar buah/${file.name}`;
    
    // Convert file to base64
    const content = await toBase64(file);
    
    const response = await fetch(
        `https://api.github.com/repos/${owner}/${repo}/contents/${path}`,
        {
            method: 'PUT',
            headers: {
                'Authorization': `token ${token}`,
                'Content-Type': 'application/json',
            },
            body: JSON.stringify({
                message: `Upload ${file.name}`,
                content: content,
                branch: 'main'
            })
        }
    );
    
    return response.json();
}

Cara Mendapatkan Token

  1. Buka GitHub → Settings → Developer settings
  2. Personal access tokens → Tokens (classic)
  3. Generate new token dengan scope "repo"
  4. Copy dan simpan token dengan aman
Buka halaman token GitHub

Tips Penting

  • Repository harus public agar gambar bisa diakses tanpa autentikasi
  • Gunakan jsDelivr CDN untuk performa lebih baik dan caching
  • Perhatikan case-sensitive - nama file harus sama persis (huruf besar/kecil)
  • Gunakan branch yang benar - bisa "main" atau "master" tergantung repository
  • Hindari file terlalu besar - GitHub memiliki batasan ukuran file
